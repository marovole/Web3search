## 审查流程

### 提交前

```bash
# 1. 运行测试
pytest

# 2. 代码格式化
black app/
isort app/

# 3. 代码检查
flake8 app/

# 4. 类型检查
mypy app/
```

### PR描述

- [ ] 变更说明清晰
- [ ] 关联Issue/Ticket
