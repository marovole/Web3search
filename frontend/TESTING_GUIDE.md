## 🐛 常见问题排查

### 问题1: 页面空白
**原因**: TypeScript编译错误或import路径错误
**解决**:
1. 检查控制台错误信息
2. 确认所有文件路径正确
3. 运行 `npm run build` 检查编译错误

### 问题2: Mock数据未加载
**原因**: 环境变量未生效
**解决**:
1. 确认 `.env.local` 存在且内容为 `VITE_USE_MOCK_API=true`
2. 重启开发服务器（Ctrl+C 停止，然后 `npm run dev`）
3. 检查控制台是否显示 "🎭 Mock API Mode Enabled"

### 问题3: SSE流式输出卡住
**原因**: MockEventSource实现问题
**解决**:
1. 打开控制台查看错误
2. 检查 `api.mock.ts` 的 MockEventSource 类
3. 确认setTimeout未被清除

### 问题4: 样式丢失
**原因**: Tailwind CSS未正确配置
**解决**:
1. 确认 `tailwind.config.js` 存在
2. 确认 `index.css` 包含 `@tailwind` 指令
3. 重启开发服务器

### 问题5: 表格渲染异常
**原因**: remark-gfm插件未加载
**解决**:
1. 确认 `package.json` 包含 `remark-gfm`
2. 确认 `MessageBubble.tsx` 中 `remarkPlugins={[remarkGfm]}`
3. 运行 `npm install` 重新安装依赖
