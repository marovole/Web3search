## ADDED Requirements
### Requirement: 代码审查对话模式
系统**SHALL**扩展现有对话界面，支持代码审查相关的交互和功能。

#### Scenario: 代码输入对话
- **WHEN** 用户在对话界面输入合约地址或代码
- **THEN** 系统识别为代码审查请求
- **AND** 自动切换到代码审查模式
- **AND** 显示代码预览和分析选项
- **AND** 提供快速分析和深度分析选择

#### Scenario: 分析结果对话展示
- **WHEN** 代码分析完成
- **THEN** 在对话界面展示结构化结果：
  - 安全漏洞列表（按严重程度排序）
  - 代码质量评分和建议
  - 可视化图表和统计数据
  - 修复建议和代码示例
- **AND** 支持交互式追问和深入分析
- **AND** 提供导出报告功能

#### Scenario: 代码审查对话历史
- **WHEN** 用户进行多次代码审查
- **THEN** 保存审查历史到对话记录
- **AND** 支持回顾之前的分析结果
- **AND** 可以对比不同版本的审查结果
- **AND** 提供代码改进追踪功能

### Requirement: 代码审查界面组件
系统**SHALL**提供专门的代码审查界面组件，集成到现有的对话系统中。

#### Scenario: 代码编辑器集成
- **WHEN** 用户查看分析结果
- **THEN** 显示内嵌代码编辑器：
  - 语法高亮和行号显示
  - 漏洞位置标记和高亮
  - 代码折叠和搜索功能
  - 实时协作编辑支持
- **AND** 支持多种区块链语言
- **AND** 提供代码格式化和验证

#### Scenario: 漏洞可视化组件
- **WHEN** 展示安全分析结果
- **THEN** 使用可视化组件：
  - 漏洞严重程度分布图
  - 代码质量雷达图
  - 函数复杂度热力图
  - 攻击向量流程图
- **AND** 支持交互式数据探索
- **AND** 提供图表导出功能

#### Scenario: 修复建议交互
- **WHEN** 用户查看修复建议
- **THEN** 提供交互式修复界面：
  - 一键应用修复代码
  - 修复前后对比视图
  - 多种修复方案选择
  - 修复效果预览
- **AND** 支持批量修复操作
- **AND** 提供修复历史记录
